# Quality checks

Run the utility tests with:

```bash
npm test
```

Run the frontend production build with:

```bash
npm run build
```

The test suite covers rule-based candidate extraction, story drafting, BRD composition and CSV escaping. It does not replace browser-based acceptance testing. Before using this prototype in a real project, test the main workflows in the target browser and review the security, privacy, accessibility and data-retention requirements.
