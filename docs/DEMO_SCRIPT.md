# Five-minute product demonstration

**Scenario:** A bank wants to simplify customer onboarding across web and branch channels.

- Start with workshop notes in Discovery Inbox.
- Extract requirements and explain that extraction is a local rules-based helper, not a connected LLM.
- Refine a requirement about identity verification and set its priority and owner.
- Draft a user story and acceptance criteria.
- Link a test case, demonstrating end-to-end traceability.
- Submit the requirement for review and record a decision.
- Open Change Impact and show what downstream artefacts would need review after a requirement changes.
- Export a baseline BRD.

The scenario and sample data are fictional and intended for demonstration only.
